# Hirst Dot Painting 🎨

A Python project inspired by the famous spot paintings of **Damien Hirst**. This project uses Python's Turtle graphics to create a colorful dot painting arranged in a grid.

## 📌 About the Project

The Hirst Dot Painting is created using Python's `turtle` module. It generates a pattern of colorful dots using randomly selected RGB colors, producing an artwork inspired by Damien Hirst's iconic paintings.

## 🛠️ Technologies Used

* **Python**
* **Turtle Graphics**
* **Random Module**

## ✨ Features

* Generates a grid of colorful dots.
* Uses randomly selected RGB colors.
* Creates unique color combinations.
* Uses Turtle graphics for drawing.
* Automates the painting process.
